## 🚀 Proyectos Destacados

### 💻 [Cipher Code Editor](https://github.com/Rmatix/cipher)
> Editor de código open source · Electron + Monaco Editor · Windows

Un editor diseñado para el futuro del desarrollo. Integra un agente de IA multi-modelo compatible con **Claude, GPT, Gemini** y modelos locales vía **Ollama / LM Studio**. Cuenta con memoria persistente, Git integrado y un debugger asistido por IA.

`Electron` `Monaco Editor` `Node.js` `xterm.js` `node-pty` `Open Source`
